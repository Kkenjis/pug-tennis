## 主な変更の流れ（2026-11-02）

1. 試作（支払い申告つき）→ 支払い機能を削除し、参加費は金額の表示だけに
2. LINE ログイン（LIFF）と Apps Script で本番公開。チームアイコンを使った PUG 仕様のデザイン
3. ゲスト機能（初めての人はゲスト、ゲスト公開の日だけ見える・回答できる）
4. セキュリティレビューと修正（数式インジェクション対策、トークン検証の強化、入力上限、再ログインの回数制限）
5. 監視（操作ログ、即時メール、日次レポート、毎朝 9 時の見回り）
6. リリースの仕組み（ブランチ保護、自動チェック、目視チェック）
7. 語尾「ワン」と PUG の感情アイコン（PR #1）
8. レビュー用資料（PR #2）

最新の仕様は [仕組みの全体像](../ARCHITECTURE.md) にまとめています。
