# PUG テニス練習 出欠管理（LINEログイン版）

チーム「PUG」の練習日を管理者が登録し、メンバーがLINEから開いて時間帯ごとに ○△× で回答・確認できるサイトです。参加費は時間枠ごとの金額設定と表示のみで、支払いの申告・確認機能はありません。

詳しい手順は「PUG テニス練習 出欠サイト 開発手順書」を参照してください。

## ファイル構成

| ファイル | 置き場所 | 役割 |
| --- | --- | --- |
| `index.html` | GitHub Pages | 画面。`CONFIG.LIFF_ID` と `CONFIG.GAS_URL` を設定 |
| `pug.png` | GitHub Pages | 丸いチームアイコン（256px・背景透過） |
| `pug-touch.png` | GitHub Pages | ホーム画面用アイコン（180px） |
| `Code.gs` | スプレッドシートのApps Script | API。`LINE_CHANNEL_ID` を設定 |

`index.html`・`pug.png`・`pug-touch.png` は同じフォルダに置きます。

## 画面の確認だけしたい場合

`index.html` をそのまま開くとデモモードで動きます（LIFF ID未設定時、または URL に `?demo`）。
- `?demo`：管理者の画面
- `?demo=member`：メンバーの画面

## 機能

- メンバー：時間枠ごとに ○参加／△未定／×不参加、ひとことコメント、参加者一覧、参加費の表示
- 管理者：複数日の一括登録（時間枠・定員・参加費）、練習日の削除
- 参加費：開始17:00より前は300円、17:00以降は500円が自動入力（変更可）。「設定」シートで基準を変更

## セットアップ（要約）

1. スプレッドシートを作り、Apps Script に `Code.gs` を貼って `setup` を実行
2. LINE Developers でLINEログインチャネルを作り、チャネルIDを `Code.gs` に設定
3. GASを「ウェブアプリ」でデプロイ（実行：自分、アクセス：全員）し、URLを控える
4. GitHub Pages に `index.html`・`pug.png`・`pug-touch.png` を置き、`CONFIG.GAS_URL` を設定
5. LIFFアプリを追加（Full、エンドポイント＝PagesのURL、Scope：openid と profile）し、`CONFIG.LIFF_ID` を設定
6. LINEログインチャネルを「公開」に切り替える
7. 自分で一度開き、「ユーザー」シートで管理者にチェック
8. `https://liff.line.me/（LIFF ID）` をLINEグループに共有

## 運用メモ

- 参加費の基準：「設定」シート（朝の参加費・ナイター参加費・ナイター開始）
- 登録済みの枠の金額：「時間枠」シートの参加費列を直接修正
- GASを更新したとき：デプロイ → デプロイを管理 → 編集 → 新バージョン（URLが変わりません）

## 仕組み（セキュリティ）

画面でLIFFがIDトークンを取得し、GASがLINEの検証API（`/oauth2/v2.1/verify`）で確認してから userId と表示名を取り出します。画面から送られた名前やIDは信用せず、管理者操作はGAS側で「ユーザー」シートの管理者チェックを確認します。コードに秘密情報は含まれないため、リポジトリは公開で問題ありません。
