### お試し環境（ステージング）（2026-11-04〜）

- 状態：案を提示。着手の合図待ち

### Issue への自動返信（2026-11-04〜）
- 要望：Issue が書き込まれたら、その場で Claude が返信する仕組みにしたい（メイン開発者）
- 決定：Claude Code GitHub Actions を使う。認証はメイン開発者のサブスクのトークン
- 安全策：起動は書き込み権限のある人だけ。権限は「読む」「Issue にコメント」のみ（コードは変更できない）
