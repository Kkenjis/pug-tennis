# PUG テニス練習 出欠管理（LINEログイン版）

チーム「PUG」の練習日を管理者が登録し、メンバーがLINEから開いて時間帯ごとに ○△× で回答・確認できるアプリです。

- 公開URL：https://liff.line.me/2012327263-i9eR8uhH （LINEのトークから開く）
- 画面：GitHub Pages（このリポジトリの main がそのまま公開されます）
- API：Google Apps Script（チーム用アカウントで運用）
- 詳しい手順：「PUG テニス練習 出欠サイト 開発手順書」「セキュリティレビュー報告書」

## 主な機能

- メンバー：時間枠ごとに ○参加／△未定／×不参加、ひとことコメント、参加者一覧、参加費の表示
- 管理者：複数日の一括登録（時間枠・定員・参加費）、削除、ゲスト公開の切り替え
- ゲスト：初めて開いた人はゲスト。ゲスト公開の日だけ見えて回答できる。管理者が「ユーザー」シートでメンバーに切り替える
- 参加費：開始17:00より前は300円、17:00以降は500円が自動入力（「設定」シートで変更）
- 監視：操作ログシート、不審な操作の即時メール、毎朝8時台の日次レポート、毎朝9時の見回り（Claudeの定期タスク「妖精さん」）
- 画面の言葉：語尾は「ワン！／ワン」、語尾のあとにはPUGの感情アイコン（うれしい・ふつう・しょんぼり・あせり）

## 更新のルール（リリースのGOサイン）

体制・権限・不在時の代行については [体制と運用ルール](docs/OPERATIONS.md) を参照してください。

main への直接の変更はできません。次の順番で進め、2つのチェックが合格するまでマージ（公開）できない仕組みです。

1. ブランチを作って変更し、プルリクエストを作る（本文に目視チェックリストが自動で入る）
2. **security-check**（自動）：エスケープ漏れ、不審な外部スクリプトや送信先、秘密情報、管理者チェックの欠落などを検査
3. **human-check**（人）：変更した本人以外が差分とデモ画面を目視で確認し、チェックリストをすべて [x] にする
4. 2つとも合格したらマージ → GitHub Pages に自動で反映
5. `gas/Code.gs` を変えた場合は、マージ後にチーム用アカウントで Apps Script に反映し、「デプロイを管理」から新バージョンにする（URLは変えない）

デモ画面での確認：`index.html?demo`（管理者）、`?demo=member`（メンバー）、`?demo=guest`（ゲスト）

## 仕組み（セキュリティ）

画面でLIFFがIDトークンを取得し、Apps Script がLINEの検証APIで確認してから userId と表示名を取り出します。画面から送られた名前やIDは信用せず、管理者操作とゲスト制限はサーバー側で判定します。コードに秘密情報は含まれないため、リポジトリは公開で問題ありません。
