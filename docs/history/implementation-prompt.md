## 依頼内容

テニスチーム「PUG」の練習日スケジュール登録と参加状況を管理するWebサイトを、このフォルダの試作コードを土台に、本番運用できる状態まで仕上げてください。試作がフォルダにない場合は、下記の仕様どおりに新規作成してください。

## 前提・方針（変更しないでください）

- 視認性・操作性はシンプルに。スマホ（LINEアプリ内ブラウザ）での利用が中心
- LINEから取得する情報は表示名のみ（スコープは `openid` と `profile`）。本人判別用の userId は保存するが画面には出さない
- 利用者のアカウント作成は不要。LINEのトークからリンクを開くだけで使える
- 費用は無料枠内（GitHub Pages＋LIFF＋Google Apps Script＋スプレッドシート）
- コードに秘密情報（チャネルシークレット等）を入れない。リポジトリは公開でよい
- **参加費は金額の設定と表示のみ。支払いの申告・確認・集金機能は作らない**

## デザイン（チーム「PUG」仕様）

- チームアイコンを `pug.png`（丸・背景透過）と `pug-touch.png`（ホーム画面用）として使用。ヘッダー左、空表示、favicon に表示
- 配色はパグの毛色（ベージュ #ecd3a6）、マズル（こげ茶 #3b2f2a）、テニスボール（黄緑 #c5dd3b）、舌のピンク（自分の名前の下線）。ダークモードも同系色
- 丸ゴシック（Google Fonts の M PLUS Rounded 1c）、うっすら肉球柄の背景、ピル型ボタン、土曜青・日曜赤の日付バッジ、跳ねるテニスボールの読み込み表示
- メッセージはところどころ「〜ワン」（例：参加時「参加ありがとうワン！🎾」）。エラーや管理者向けは通常の丁寧語

## 構成

- 画面：`index.html` 1ファイル（素のHTML/CSS/JS、ビルドなし）を GitHub Pages で公開し、LIFF（Full サイズ）で開く
- API：GAS ウェブアプリ（`doPost`）。実行ユーザー＝自分、アクセス＝全員
- データ：GAS に紐づくスプレッドシート
- 認証：画面で `liff.getIDToken()` → GAS が `https://api.line.me/oauth2/v2.1/verify`（`id_token`・`client_id`=チャネルID）で検証。画面から送られた名前やIDは信用しない
- 通信：`fetch` は `Content-Type: text/plain;charset=utf-8` で送り、CORSプリフライトを回避

## 機能仕様

**メンバー**
- 当日以降の練習日をカードで日付順に表示（日付・曜日・場所・メモ）
- 1つの練習日に複数の時間枠。時間枠ごとに ○参加／△未定／×不参加 を選ぶ。選択中のボタンをもう一度押すと取り消し
- 回答済みの枠には任意のひとことコメント（100文字まで）
- 枠ごとに ○△× 別の参加者名を回答が早い順に表示。自分の名前は強調
- 定員（0=無制限）に達した枠は ○ を押せない（サーバー側でもチェック）
- 時間枠の見出しに参加費を表示し、○ を選ぶと「参加費 ¥500 です」と案内

**管理者**
- 「ユーザー」シートの「管理者」チェックが入った人だけ「練習日を登録」タブを表示
- 複数の日付を選び、共通の場所・メモ・時間枠（開始・終了・定員・参加費を複数行）で一括登録
- 練習日ごとの削除（時間枠と回答もまとめて削除、確認ダイアログあり）
- 管理操作はGAS側でも必ず権限確認

**参加費の金額ルール**
- 開始時刻がナイター開始（初期値17:00）より前＝朝の参加費（初期値300円）、以降＝ナイター参加費（初期値500円）
- 登録画面では開始時刻から自動入力し、手で変更した値を優先
- 時間枠ごとに1回分。0円なら表示しない

**スプレッドシート（`setup()` で自動作成。再実行で列・設定項目の追加にも対応）**
- 開催日：eventId, 日付(yyyy-MM-dd), 場所, メモ, 登録日時
- 時間枠：slotId, eventId, 開始(HH:mm), 終了(HH:mm), 定員, 参加費(円)
- 出欠：slotId, userId, 表示名, 出欠(○△×), コメント, 更新日時
- ユーザー：userId, 表示名, 最終アクセス, 管理者(チェックボックス)
- 設定：朝の参加費(300), ナイター参加費(500), ナイター開始(17:00)
- 日付・時刻・IDが自動変換されないよう文字列書式で保存。手入力の `2026/11/8` や `9:00` も読める
- 書き込みは `LockService` で排他制御
